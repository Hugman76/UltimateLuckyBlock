# ⁉️ Ultimate Lucky Block

## Installation

Ultimate Lucky Block is only needed on the server. Note it can be also played on singleplayer.

⚠ Ultimate Lucky Block **needs** the following mods to be installed:
- Polymer
- Fabric API: [GitHub](https://github.com/FabricMC/fabric) / [Modrinth](https://modrinth.com/mod/fabric-api) / [CurseForge](https://www.curseforge.com/minecraft/mc-mods/fabric-api)

Polymer's AuthHost MUST be enabled on servers to display content correctly on clients. Visit [Polymer's documentation](https://polymer.pb4.eu/latest/user/resource-pack-hosting/) for more information.
