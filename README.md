# ⁉️ Ultimate Lucky Block

## Installation

UHC can be installed on a client or a server. It is recommended to install it on a server only, though.

⚠ Ultimate Lucky Block **needs** the following mods to be installed:
- Polymer
- Fabric API: [GitHub](https://github.com/FabricMC/fabric) / [Modrinth](https://modrinth.com/mod/fabric-api) / [CurseForge](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
